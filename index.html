fethr.

A featherweight code editor with a first‑class agent panel.

The agent reads your project and proposes edits as diffs. You accept them in the editor, where ⌘Z still works. The agent process never touches your disk.

$npx @evojewel/fethr@alpha .
Download for macOS0.9.3-alpha · Apple Silicon · 40 MB

Either way you need Node 18 or newer and a Claude Code login on the machine. Details under before you run it.

How it is put together

Proposes, never writes

The agent can read, grep and glob inside the folder you opened, and nothing else: every mutating tool is disabled server-side. Its one way to change anything is propose_edit, which shows you a diff card. You accept or reject.

A peer process, not a plugin

The agent runs on the Claude Agent SDK with the Claude Code login already on your machine, so there is no API key to configure. The editor pipes context in and renders what comes back. There is no extension platform to carry.

Your browser is the shell

fethr starts a local server on 127.0.0.1 and opens your browser, the rendering engine your OS already ships. CodeMirror 6 underneath. No Electron. The native macOS window bundles the same server and shows the same page.

In the panel

  • Context you can see. A pill row above the composer shows exactly what rides along with your next message: the current file, the live selection, the real git branch, and any file you attached by typing @.
  • Live status. Thinking, the tool in use, writing. Streamed thinking sits in a collapsible block, and there is a stop button.
  • Clickable references. app.js:42 in a reply jumps the editor to that file and line.
  • Model picker. Default, opus, sonnet, haiku or fable 5. Switching starts a fresh conversation.
  • Auto mode. Proposals apply straight to the buffer, still undoable with ⌘Z. Off by default.
  • Voice input. The mic button uses the browser's built-in speech recognition in Chromium-based browsers. No server, no key.
  • Chat history persists per project, panels resize by dragging and remember their widths, ⌘J toggles the panel and ⌘B the sidebar.
  • Highlighting for JavaScript and TypeScript, Python, Markdown, HTML, CSS and JSON.

Before you run it

Alpha. It works, and it has rough edges. What shipped in each version is in the changelog; the design decisions and the bugs behind them are in ARCHITECTURE.md.

You need Claude Code. The panel uses the login already on your machine, and tells you if there is none. The native app also needs a Node install it can find (Homebrew or nvm), because it runs the same server as the command line does.

What leaves your machine. The editor itself makes no network calls. The agent panel does: the current file, your selection and anything you attach go to Anthropic's API through your Claude Code login, the same as using Claude Code directly. Don't open the panel on files you don't want leaving your machine.

Scope. File access is confined to the folder you launch with, symlinks included. A Finder double-click asks you to choose a folder rather than opening your home directory.

First launch of the app. The build is signed but not notarized, so macOS blocks it once. Allow it under System Settings, Privacy & Security, then open it again.
